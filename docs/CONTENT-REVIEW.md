# Протокол проверки контента (стандарт для любой правки текстов)

Применяется к каждому уроку, игре, блоку «Для взрослого / для родителей»,
FAQ и любому новому тексту на сайте — до коммита. Работа идёт этапами; на
каждом этапе — одна роль и её чек-лист. Каждая находка записывается в
таблицу находок (где → что не так → как исправлено → чем проверено) в
описании PR. «Проверено» = реально запущено или прочитано, не предположено.

Эталон смысла — русский текст. Остальные 9 языков сверяются с ним.

## Этап 0. Хранитель правил — свод, с которым сверяются все этапы
- 4 возраста: 5–7 (со взрослым, взрослый читает вслух), 8–10, 11–13, 14+.
- 10 языков: en ru de es fr hi id pt tr vi. Новый текст — сразу во всех.
- Нет регистрации, аналитики, рекламы, внешнего чата, сбора ответов детей,
  камеры/микрофона. Ребёнок ничего не вводит о себе.
- Не писать «проверено носителем / педагогом / с детьми», если этого не было.
  Флаги review в реестре — false, пока проверки не было.
- Источники и примеры сервисов — доступные и законные в стране языка.
- Не выдумывать факты, цифры, названия, результаты проверок.
- Демо честно названо демо: тексты помощника написаны заранее, данные вымышлены.

## Этап 1. Методист-логик (по эталону RU)
- У каждого вопроса ровно один верный ответ; неверные — правдоподобны, но
  однозначно неверны; объяснение есть для каждого неверного.
- Отклик соответствует действию ребёнка (оценивается то, что он сделал, а не
  итог модели); нет «Ошибка!» за верную мысль.
- Ответ не подсказан заранее (ни в тексте шага, ни в «Объяснении» на странице).
- Верный ответ не стоит всегда первым (движок перемешивает 3+ варианта).
- Нет «подстроенности», которую нельзя честно объяснить ребёнку.
- Склейка текста из кусочков читается как нормальные предложения.
- «Необязательное» не считается ошибкой (needed: null).

## Этап 2. Возрастной педагог (по каждому возрасту)
- 5–7: история и конкретные предметы вместо абстракций; короткие фразы;
  бытовые слова (не «модель», «обучающие данные», «переобучить»); взрослый
  читает; ответ — показать пальцем или сказать.
- 8–10: термины только с объяснением; одно действие за шаг.
- 11–13: причины, проверка, сравнение источников.
- 14+: ограничения метода, последствия, кто получает данные.
- Сложность растёт от возраста к возрасту; ни один возраст не «одинаковый для всех».
- Нейтрально к полу ребёнка (в языках с родом — формы без рода или «мы»).

## Этап 3. Научный редактор
- Каждое утверждение о ИИ подтверждается указанным источником (что именно
  подтверждает — в поле «Что подтверждает»), без преувеличений.
- Ссылки открыты и проверены (дата проверки в реестре).
- Демо-правила, которых нет в реальном ML, названы для взрослого.

## Этап 4. Безопасность и приватность детей
- Все имена, адреса, телефоны вымышлены; телефоны — из нулей; нет реальных школ
  и узнаваемых людей.
- Урок не учит делиться данными и не просит ввести что-то о себе.
- Тексты о сервисах не утверждают того, что мы не можем знать (кто видит
  данные, как долго хранит).

## Этап 5. Блок для взрослых и родителей
- Цель, вопросы, типичное заблуждение, признаки понимания, метод — совпадают с
  тем, что ребёнок видит во ВСЕХ возрастах (одинаковые слова или нейтральные).
- Печатное задание выполнимо на бумаге, ответы к нему верны и совпадают с уроком.
- Раздел «Для родителей» на главных: никаких обещаний сверх реальности
  (приватность, «безопасно», «научно доказано» — только с основанием).

## Этап 6. Редактор-локализатор (каждый язык отдельно)
- Смысл совпадает с эталоном RU (включая все исправления этапов 1–5).
- Естественно для языка; местные имена, валюта, формат времени, обращение
  (de: du ребёнку / Sie взрослому; fr/es: tu), типографика (fr: неразрывные
  пробелы; de: „…“).
- Название раздела совпадает с шапкой сайта на этом языке.
- Без пометок «проверено носителем».

## Этап 7. QA
- `node tools/gen-series.mjs && node tools/gen-entry.mjs && node tools/build.mjs --check`
- `node --test "tests/**/*.test.mjs"` — 0 fail.
- Бот-прохождение (телефон 390 px, касания): все уроки × возрасты × языки до
  конца, сначала неверные ответы; 0 ошибок JS, 0 горизонтальной прокрутки.
- Скриншоты изменённых экранов; Lighthouse ключевых страниц (CLS < 0.1).
- На каждый найденный класс ошибок — автотест, который падает на старом тексте.

## Этап 8. Выпуск
- Коммит с содержательным описанием и таблицей находок; ветка → PR.
- Merge и деплой — только по команде владельца («МЕРЖ»); после — `gh run list`
  до зелёного verify и проверка живых страниц.
