# Мастер-план Kids AI Test — с 2026-11-09

Главный план работы. Читать в начале каждой сессии вместе с `docs/SESSION-PROMPT.md`.
Владелец пишет «1» = беру первую незакрытую подзадачу сверху вниз (кусок ≤ 5 минут), делаю, сохраняю
(коммит/пуш/PR), ставлю статус здесь, отвечаю одной строкой.
Статусы: `[ ]` не начато · `[~]` идёт · `[x]` сделано (с доказательством) · `[!]` нужен владелец.

## 0. Как работать (коротко; полный текст — SESSION-PROMPT.md)

**Общий промт на каждый кусок:**
> Ты — {роль} мирового уровня. Задача: {подзадача}. Сначала открой первоисточник (правило, закон,
> исследование) и выпиши дословную цитату + URL. Потом проверь сайт против неё: страница, язык, возраст.
> Найденное — таблицей «было → стало → почему → источник». Правь скриптом с пробным прогоном.
> Проверь: тесты на последнем коммите, 10 языков, 4 возраста, живой сайт после выкладки.
> Отчёт в две колонки: «проверил сам (чем)» / «не проверял, по памяти».

**Роли (выбираю под задачу):** юрист (законы о детях и ИИ) · литредактор языка страницы · педагог
по возрастам · учёный-фактчекер · специалист по безопасности детей в сети · SEO-специалист Google ·
специалист по доступности (WCAG) · программист + хакер · дизайнер/UX · локализатор страны · носитель языка.

**Честность (правила <truth>, PR #54):** «проверено» только с доказательством этой сессии;
пробный прогон ≠ проверка перевода; «N из M»; источник — только если открыт и подтверждает.
