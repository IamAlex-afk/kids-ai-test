Privacidad

En resumen

  • No hay registro. No pedimos nombre, correo ni la edad del niño, y no recogemos respuestas.
  • No hay cookies, analítica, publicidad ni contadores de visitas.
  • Por defecto, el progreso se guarda solo en esta pestaña y desaparece al cerrarla.

Qué se guarda en tu navegador

  • Si no eliges otra cosa, solo en esta pestaña: lecciones terminadas y resultados de los juegos. Cierras la pestaña y desaparece.
  • Si pulsas 💾 y activas el guardado en este dispositivo, los mismos datos quedan en el navegador hasta que lo desactives. Al desactivarlo se borran solo los registros de este sitio.
  • Para que el sitio funcione sin internet, el navegador guarda una copia de sus páginas e imágenes. Son archivos del sitio, no tus datos.
  • El número de la tarjeta y el código SHA-256 se calculan en el navegador. La tarjeta es un recuerdo, no un certificado: no demuestra quién eres.

Qué no se envía a ninguna parte

  • La lectura en voz alta usa solo voces instaladas en el dispositivo. Si no hay ninguna, aparece un aviso en lugar del botón «Escuchar»: no usamos voces en línea.
  • El botón «Compartir» abre el menú habitual del teléfono o del navegador. El sitio no envía nada.

Alojamiento: qué ve GitHub

El sitio está alojado en GitHub Pages. GitHub indica que, cuando se visita un sitio de GitHub Pages, la dirección IP del visitante se registra y se guarda por motivos de seguridad, aunque no haya iniciado sesión en GitHub. GitHub no dice durante cuánto tiempo. Nosotros no vemos ni usamos esos datos.

Fuente: GitHub Docs, «What is GitHub Pages?»

Enlaces a otros sitios

El sitio enlaza a GitHub, a la página de apoyo del proyecto (ko-fi), a los tests del autor para adultos (Mind-OS) y a las fuentes de los datos. Son otros sitios con sus propias normas de privacidad.

Cómo borrarlo todo

  1. Pulsa 💾 y desactiva el guardado: se borran los registros del sitio.
  2. O borra los datos de este sitio en la configuración del navegador; así también se elimina la copia sin conexión.
