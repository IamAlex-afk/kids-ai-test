Privacidade

Em resumo

  • Não há cadastro. Não pedimos nome, e-mail nem a idade da criança, e não coletamos respostas.
  • Não há cookies, análise de dados, anúncios nem contadores de visitas.
  • Por padrão, o progresso fica só nesta aba e some quando você a fecha.

O que fica guardado no seu navegador

  • Se você não escolher outra coisa, só nesta aba: lições concluídas e resultados dos jogos. Fechou a aba, sumiu.
  • Se você tocar em 💾 e ativar o salvamento neste aparelho, os mesmos dados ficam no navegador até você desativar. Ao desativar, só os registros deste site são apagados.
  • Para o site funcionar sem internet, o navegador guarda uma cópia das páginas e imagens. São arquivos do site, não os seus dados.
  • O número do cartão e o código SHA-256 são calculados no navegador. O cartão é uma lembrança, não um certificado: não comprova quem você é.

O que não é enviado para lugar nenhum

  • A leitura em voz alta usa só vozes instaladas no aparelho. Se não houver nenhuma, aparece um aviso no lugar do botão “Ouvir” — não usamos vozes on-line.
  • O botão “Compartilhar” abre o menu normal do celular ou do navegador. O site em si não envia nada.

Hospedagem: o que o GitHub vê

O site está hospedado no GitHub Pages. O GitHub informa que, quando um site do GitHub Pages é visitado, o endereço IP do visitante é registrado e guardado por motivos de segurança, mesmo sem login no GitHub. O GitHub não diz por quanto tempo. Nós não vemos nem usamos esses dados.

Fonte: GitHub Docs, “What is GitHub Pages?”

Como apagar tudo

  1. Toque em 💾 e desative o salvamento — os registros do site são apagados.
  2. Ou apague os dados deste site nas configurações do navegador — isso também remove a cópia off-line.
