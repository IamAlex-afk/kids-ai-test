Confidentialité

En bref

  • Il n’y a pas d’inscription. Nous ne demandons ni nom, ni e-mail, ni l’âge de l’enfant, et nous ne collectons pas les réponses.
  • Il n’y a ni cookies, ni mesure d’audience, ni publicité, ni compteur de visites.
  • Par défaut, la progression reste seulement dans cet onglet et disparaît quand on le ferme.

Ce qui est gardé dans votre navigateur

  • Sauf choix contraire, seulement dans cet onglet : les leçons terminées et les résultats des jeux. On ferme l’onglet, tout disparaît.
  • Si vous appuyez sur 💾 et activez l’enregistrement sur l’appareil, les mêmes données restent dans le navigateur jusqu’à ce que vous le désactiviez. La désactivation supprime seulement les données de ce site.
  • Pour que le site fonctionne hors ligne, le navigateur garde une copie de ses pages et de ses images. Ce sont les fichiers du site, pas vos données.
  • Le numéro de la carte et le code SHA-256 sont calculés dans le navigateur. La carte est un souvenir, pas un certificat : elle ne prouve pas votre identité.

Ce qui n’est envoyé nulle part

  • La lecture à voix haute utilise seulement les voix installées sur l’appareil. S’il n’y en a pas, un message remplace le bouton « Écouter » : nous n’utilisons pas de voix en ligne.
  • Le bouton « Partager » ouvre le menu habituel du téléphone ou du navigateur. Le site lui-même n’envoie rien.

Hébergement : ce que voit GitHub

Le site est hébergé sur GitHub Pages. GitHub indique que, lors de la visite d’un site GitHub Pages, l’adresse IP du visiteur est enregistrée et conservée pour des raisons de sécurité, même sans connexion à GitHub. GitHub ne précise pas la durée. Nous ne voyons pas et n’utilisons pas ces données.

Source : GitHub Docs, « What is GitHub Pages? »

Liens vers d’autres sites

Le site renvoie vers GitHub, la page de soutien du projet (ko-fi), les tests de l’auteur pour adultes (Mind-OS) et les sources des faits. Ce sont d’autres sites, avec leurs propres règles de confidentialité.

Comment tout supprimer

  1. Appuyez sur 💾 et désactivez l’enregistrement : les données du site sont supprimées.
  2. Ou effacez les données de ce site dans les réglages du navigateur : cela supprime aussi la copie hors ligne.

Vous avez trouvé une erreur ? Écrivez-nous sur GitHub. Le code est ouvert : chacun peut vérifier ce que fait vraiment le site. Écrire sur GitHub
