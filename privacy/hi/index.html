गोपनीयता

छोटे में

  • कोई रजिस्ट्रेशन नहीं है। हम नाम, ईमेल या बच्चे की उम्र नहीं पूछते और जवाब इकट्ठा नहीं करते।
  • कोई कुकीज़, एनालिटिक्स, विज्ञापन या विज़िट काउंटर नहीं हैं।
  • शुरू में प्रगति सिर्फ़ इसी टैब में रहती है और टैब बंद करते ही मिट जाती है।

आपके ब्राउज़र में क्या रखा जाता है

  • आपकी पसंद के बिना सिर्फ़ इसी टैब में: पूरे किए गए पाठ और खेलों के नतीजे। टैब बंद किया — सब मिट गया।
  • अगर आप 💾 दबाकर इस डिवाइस पर सेव करना चालू करते हैं, तो वही डेटा ब्राउज़र में तब तक रहता है जब तक आप इसे बंद न करें। बंद करने पर सिर्फ़ इसी साइट का डेटा मिटता है।
  • साइट बिना इंटरनेट के चल सके, इसके लिए ब्राउज़र उसके पेजों और तस्वीरों की एक कॉपी रखता है। ये साइट की फ़ाइलें हैं, आपका डेटा नहीं।
  • कार्ड का नंबर और SHA-256 कोड ब्राउज़र में ही बनते हैं। कार्ड एक यादगार है, प्रमाणपत्र नहीं: इससे आपकी पहचान साबित नहीं होती।

क्या कहीं नहीं भेजा जाता

  • पढ़कर सुनाने के लिए सिर्फ़ डिवाइस पर इंस्टॉल आवाज़ों का इस्तेमाल होता है। अगर ऐसी आवाज़ नहीं है, तो “सुनें” बटन की जगह एक संदेश दिखता है — हम ऑनलाइन आवाज़ें इस्तेमाल नहीं करते।
  • “शेयर करें” बटन फ़ोन या ब्राउज़र का सामान्य मेनू खोलता है। साइट ख़ुद कुछ नहीं भेजती।

होस्टिंग: GitHub क्या देखता है

यह साइट GitHub Pages पर है। GitHub के अनुसार, GitHub Pages की साइट पर आने वाले हर व्यक्ति का IP पता सुरक्षा के लिए दर्ज करके रखा जाता है — भले ही उसने GitHub में लॉग इन न किया हो। GitHub यह नहीं बताता कि कितने समय तक। हम यह डेटा न देखते हैं, न इस्तेमाल करते हैं।

स्रोत: GitHub Docs, “What is GitHub Pages?”

दूसरी साइटों के लिंक

साइट पर GitHub, प्रोजेक्ट के सहयोग पेज (ko-fi), लेखक के वयस्कों के लिए टेस्ट (Mind-OS) और तथ्यों के स्रोतों के लिंक हैं। ये अलग साइटें हैं, जिनके अपने गोपनीयता नियम हैं।

सब कुछ कैसे मिटाएँ

  1. 💾 दबाएँ और सेव करना बंद करें — साइट का डेटा मिट जाएगा।
  2. या ब्राउज़र की सेटिंग्स में इस साइट का डेटा मिटाएँ — इससे बिना इंटरनेट वाली कॉपी भी हट जाएगी।

कोई ग़लती मिली? हमें GitHub पर लिखें। सोर्स कोड खुला है: कोई भी जाँच सकता है कि साइट असल में क्या करती है। GitHub पर लिखें
