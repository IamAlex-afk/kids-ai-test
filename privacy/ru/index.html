Конфиденциальность

Коротко

  • Регистрации нет. Мы не спрашиваем имя, почту или возраст ребёнка и не собираем ответы.
  • Куки, аналитики, рекламы и счётчиков посещений нет.
  • Прогресс по умолчанию хранится только в этой вкладке и исчезает, когда её закрыть.

Что хранится в вашем браузере

  • Без вашего выбора — только в этой вкладке: пройденные уроки и результаты игр. Закрыли вкладку — всё исчезло.
  • Если нажать 💾 и включить сохранение на устройстве, то же самое хранится в браузере, пока вы его не выключите. Выключение удаляет только записи этого сайта.
  • Чтобы сайт работал без интернета, браузер хранит копию его страниц и картинок. Это файлы сайта, а не ваши данные.
  • Номер карточки и код SHA-256 считаются в браузере. Это сувенир, а не сертификат: они не подтверждают личность.

Что никуда не отправляется

  • Озвучка использует только голоса, установленные на устройстве. Если такого голоса нет, вместо кнопки «Слушать» появится сообщение — онлайн-голоса мы не используем.
  • Кнопка «Поделиться» открывает обычное меню телефона или браузера. Сам сайт ничего не отправляет.

Хостинг: что видит GitHub

Сайт размещён на GitHub Pages. GitHub пишет, что при посещении сайта на GitHub Pages IP-адрес посетителя записывается и хранится в целях безопасности — даже если вы не входили в GitHub. Срок хранения GitHub не указывает. Мы этих данных не видим и не используем.

Источник: GitHub Docs, «What is GitHub Pages?»

Как удалить всё

  1. Нажмите 💾 и выключите сохранение — записи сайта будут удалены.
  2. Или удалите данные сайта в настройках браузера — это удалит и копию для работы без интернета.
