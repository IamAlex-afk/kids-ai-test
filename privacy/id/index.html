Privasi

Singkatnya

  • Tidak ada pendaftaran. Kami tidak menanyakan nama, email, atau usia anak, dan tidak mengumpulkan jawaban.
  • Tidak ada cookie, analitik, iklan, atau penghitung kunjungan.
  • Secara bawaan, kemajuan hanya tersimpan di tab ini dan hilang saat tab ditutup.

Apa yang tersimpan di browser Anda

  • Kecuali Anda memilih lain, hanya di tab ini: pelajaran yang selesai dan hasil permainan. Tab ditutup, semuanya hilang.
  • Jika Anda menekan 💾 dan menyalakan penyimpanan di perangkat ini, data yang sama tetap ada di browser sampai Anda mematikannya. Saat dimatikan, hanya data situs ini yang dihapus.
  • Agar situs bisa dipakai tanpa internet, browser menyimpan salinan halaman dan gambarnya. Itu file situs, bukan data Anda.
  • Nomor kartu dan kode SHA-256 dihitung di browser. Kartu itu kenang-kenangan, bukan sertifikat: tidak membuktikan siapa Anda.

Apa yang tidak dikirim ke mana pun

  • Fitur membaca dengan suara hanya memakai suara yang terpasang di perangkat. Jika tidak ada, muncul pesan sebagai ganti tombol “Dengarkan” — kami tidak memakai suara online.
  • Tombol “Bagikan” membuka menu biasa ponsel atau browser. Situs ini sendiri tidak mengirim apa pun.

Hosting: apa yang dilihat GitHub

Situs ini di-hosting di GitHub Pages. GitHub menyebutkan bahwa saat situs GitHub Pages dikunjungi, alamat IP pengunjung dicatat dan disimpan untuk keamanan, meskipun pengunjung tidak masuk ke GitHub. GitHub tidak menyebutkan berapa lama. Kami tidak melihat dan tidak memakai data ini.

Sumber: GitHub Docs, “What is GitHub Pages?”

Tautan ke situs lain

Situs ini menautkan ke GitHub, halaman dukungan proyek (ko-fi), tes penulis untuk orang dewasa (Mind-OS), dan sumber fakta. Itu situs lain dengan aturan privasinya sendiri.

Cara menghapus semuanya

  1. Tekan 💾 dan matikan penyimpanan — data situs dihapus.
  2. Atau hapus data situs ini di pengaturan browser — salinan offline juga ikut terhapus.
