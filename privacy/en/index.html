Privacy

In short

  • There is no sign-up. We do not ask for a name, an email or a child’s age, and we do not collect answers.
  • There are no cookies, analytics, ads or visit counters.
  • By default, progress is kept only in this tab and disappears when you close it.

What is kept in your browser

  • Unless you choose otherwise, only in this tab: finished lessons and game results. Close the tab and it is gone.
  • If you press 💾 and turn on saving on this device, the same data stays in the browser until you turn it off. Turning it off deletes only this site’s records.
  • So the site works offline, the browser keeps a copy of its pages and pictures. These are the site’s files, not your data.
  • The card number and the SHA-256 code are worked out in the browser. The card is a keepsake, not a certificate: it does not prove who you are.

What is not sent anywhere

  • Reading aloud uses only voices installed on the device. If there is no such voice, a message appears instead of the “Listen” button — we do not use online voices.
  • The “Share” button opens the usual menu of the phone or browser. The site itself sends nothing.

Hosting: what GitHub sees

The site is hosted on GitHub Pages. GitHub says that when a GitHub Pages site is visited, the visitor’s IP address is logged and stored for security purposes, even if the visitor is not signed in to GitHub. GitHub does not say how long it is kept. We do not see or use this data.

Source: GitHub Docs, “What is GitHub Pages?”

Links to other sites

The site links to GitHub, the project’s support page (ko-fi), the author’s tests for adults (Mind-OS) and the sources of facts. These are other sites with their own privacy rules.

How to delete everything

  1. Press 💾 and turn saving off — the site’s records are deleted.
  2. Or clear this site’s data in your browser settings — this also removes the offline copy.

Found a mistake? Tell us on GitHub. The source code is open: anyone can check what the site really does. Write on GitHub
