Datenschutz

Kurz gesagt

  • Es gibt keine Anmeldung. Wir fragen nicht nach Name, E-Mail oder Alter des Kindes und sammeln keine Antworten.
  • Es gibt keine Cookies, keine Analyse, keine Werbung und keine Besucherzähler.
  • Standardmäßig bleibt der Fortschritt nur in diesem Tab und verschwindet, wenn du ihn schließt.

Was in deinem Browser gespeichert wird

  • Ohne deine Wahl nur in diesem Tab: abgeschlossene Lektionen und Spielergebnisse. Tab schließen – alles ist weg.
  • Wenn du 💾 drückst und das Speichern auf dem Gerät einschaltest, bleiben dieselben Daten im Browser, bis du es ausschaltest. Beim Ausschalten werden nur die Einträge dieser Website gelöscht.
  • Damit die Website offline funktioniert, speichert der Browser eine Kopie ihrer Seiten und Bilder. Das sind Dateien der Website, nicht deine Daten.
  • Die Kartennummer und der SHA-256-Code werden im Browser berechnet. Die Karte ist ein Andenken, kein Zertifikat: Sie beweist nicht, wer du bist.

Was nirgendwohin gesendet wird

  • Das Vorlesen nutzt nur Stimmen, die auf dem Gerät installiert sind. Gibt es keine solche Stimme, erscheint statt der Schaltfläche „Anhören“ ein Hinweis – Online-Stimmen nutzen wir nicht.
  • Die Schaltfläche „Teilen“ öffnet das normale Menü des Handys oder Browsers. Die Website selbst sendet nichts.

Hosting: was GitHub sieht

Die Website liegt auf GitHub Pages. GitHub schreibt, dass beim Besuch einer GitHub-Pages-Website die IP-Adresse des Besuchers aus Sicherheitsgründen protokolliert und gespeichert wird – auch ohne Anmeldung bei GitHub. Wie lange, gibt GitHub nicht an. Wir sehen und nutzen diese Daten nicht.

Quelle: GitHub Docs, „What is GitHub Pages?“

Links zu anderen Websites

Die Website verlinkt auf GitHub, die Unterstützungsseite des Projekts (ko-fi), die Tests des Autors für Erwachsene (Mind-OS) und die Quellen der Fakten. Das sind andere Websites mit eigenen Datenschutzregeln.

So löschst du alles

  1. Drücke 💾 und schalte das Speichern aus – die Einträge der Website werden gelöscht.
  2. Oder lösche die Daten dieser Website in den Browser-Einstellungen – das entfernt auch die Offline-Kopie.
