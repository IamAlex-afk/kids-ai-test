# Security Policy

## Supported Versions

Only the latest version deployed at
https://iamalex-afk.github.io/kids-ai-test/ is supported.

## Architecture

Kids AI Test is a browser-only static PWA on GitHub Pages.

- No server — no backend to attack
- No database — no data to steal
- No user accounts — no credentials to compromise
- No ads, no trackers, no analytics
- All progress stored in the user's own browser (localStorage)
- Content Security Policy active
- Service worker caches static assets only, no user data

## Reporting a Vulnerability

Report security issues via GitHub Issues:
https://github.com/IamAlex-afk/kids-ai-test/issues

Expected response time: within 7 days.
